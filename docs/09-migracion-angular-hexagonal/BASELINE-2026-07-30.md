## Validación ejecutada

Se construyó HCOP_AJP en Docker y se levantó una instalación limpia aislada en
`http://127.0.0.1:5181`. La instancia estable de `http://127.0.0.1:5180`
permaneció saludable y no compartió redes, base ni volúmenes.

Resultados:

- 19 suites Java aprobadas, sin fallos ni errores.
- JAR generado correctamente.
- Lanzador validado con Windows PowerShell 5.1.
- Salud, login, núcleo clínico y Configuración aprobados.
- 111 operaciones OpenAPI verificadas.
- 49 documentos y enlaces verificados.
- Flujo integral completado con paciente, diagnóstico, tratamiento, cuatro
  drogas, turno, Farmacia, triaje, preparación, interrupción, reanudación,
  administración y cinco evoluciones.

La prueba se ejecutó durante la franja en la que UTC ya correspondía al día
siguiente. El laboratorio utilizó correctamente la fecha clínica de Buenos
Aires y dejó de producir el falso error de fecha futura.

## Riesgos que la migración debe controlar

- `app.js` concentra múltiples dominios y efectos compartidos.
- Algunos contratos utilizan objetos genéricos y formas históricas.
- La hoja narrativa JSON y las tablas operativas necesitan autoridades
  explícitas para evitar duplicación.
- Turnos y workflow requieren concurrencia, idempotencia y auditoría.
- El editor de imágenes, arrastrar/soltar y la grilla de sillones tienen alta
  complejidad visual.
- Los permisos deben comprobarse tanto en Angular como en el servidor.
- La migración debe conservar acceso a una base existente, no sólo funcionar
  sobre una instalación vacía.
