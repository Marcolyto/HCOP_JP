# Material audiovisual: flujo oncológico

Este directorio reúne el resumen original y los subtítulos editables del nuevo
recorrido detallado.

- `capturas/`: siete PNG obtenidos del navegador con un paciente ficticio.
- `flujo-oncologico-7-pasos.srt`: guion subtitulado editable.
- `flujo-oncologico-7-pasos.mp4`: resumen de 70 segundos, 1080p,
  con cursor animado y subtítulos incrustados.
- `circuito-hospital-dia-paso-a-paso.srt`: subtítulos editables del recorrido
  detallado, con descripciones de acciones, condiciones y alternativas.

El nuevo MP4 que reproduce la Ayuda está publicado en
`src/main/resources/static/help/media/circuito-hospital-dia-paso-a-paso.mp4`.
Usa subtítulos azul intenso y recuadros para señalar cada zona explicada. Su
índice, diagrama y alcance funcional están en
`docs/01-uso/VIDEO-CIRCUITO-HOSPITAL-DIA-PASO-A-PASO.md`.

La guía de generación está en
`scripts/demo-video/README.md`.
