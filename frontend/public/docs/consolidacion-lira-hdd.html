Arquitectura final · julio 2026

HCOP JP funciona sin Lira, Node.js ni MySQL

La interfaz clínica y todos los flujos operativos se consolidaron en un servidor Java con PostgreSQL. El navegador accede a una sola aplicación y la base local es la única fuente clínica activa.

Datos clínicos

Repositorio limpio: GitHub y la imagen Docker incluyen código, catálogos, protocolos, migraciones y plantillas; no incluyen pacientes, tratamientos reales, adjuntos, contraseñas privadas ni la base de pruebas.

En una instalación nueva, Flyway crea la estructura vacía y las cuentas iniciales configuradas. Los pacientes se crean desde “Nuevo paciente”. Si se realiza una migración institucional, debe ejecutarse como proceso controlado, validando conteos, relaciones, hashes de archivos y muestras clínicas antes del corte.

Instalación completa

  1. El autoinstalador verifica o instala Docker Desktop.
  2. Solicita usuario, contraseña y puerto.
  3. Genera secretos aleatorios para PostgreSQL, QR y cifrado.
  4. Descarga la versión más reciente del repositorio.
  5. Obtiene la imagen publicada o la construye desde el código.
  6. Levanta PostgreSQL, espera salud y luego inicia Java.
  7. Flyway aplica las migraciones pendientes en orden.
  8. Abre la interfaz y crea lanzadores de inicio y detención.

Controles de integridad

  • Compilación y pruebas Maven en cada cambio.
  • Construcción y arranque real de Docker Compose en GitHub Actions.
  • Prueba integral de login, paciente, diagnóstico, tratamiento, turno, QR, finalización y evoluciones.
  • Restricciones de claves foráneas y estados.
  • Control optimista de revisión para evitar sobrescrituras.
  • Restricción de base para impedir superposición de sillones.
  • Escaneo de secretos y exclusión de datos locales antes de publicar.

Backup y recuperación

La recuperación completa requiere dos elementos de la misma instalación: el volumen PostgreSQL y el volumen de archivos clínicos. Se recomienda detener escrituras, crear un volcado con pg_dump, respaldar el volumen de storage y verificar la restauración en otro entorno.

No es backup: copiar el repositorio o volver a descargar la imagen no recupera pacientes ni estudios. Esos datos viven exclusivamente en los volúmenes locales.
