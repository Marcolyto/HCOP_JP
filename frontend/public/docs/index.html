Qué contiene el producto

Historia clínica

Hoja clínica, evoluciones inmutables, diagnósticos SNOMED/CIE-10/AJCC/TNM, estudios y archivos.

Tratamientos

Protocolos, drogas, preparación, duración, ciclos, consentimiento, receta y hoja de tratamiento.

Hospital de Día

Farmacia, QR firmado, sillones, prevención de superposición, administración, suspensión y continuidad.

Configuración

Protocolos, guías, calculadoras, formularios, plantillas, diagnósticos, LLM, usuarios, roles y permisos.

Instalación
Docker Compose levanta la aplicación y PostgreSQL. Flyway crea o actualiza la estructura automáticamente.
Datos
Los pacientes y adjuntos se guardan en volúmenes locales; no forman parte de GitHub ni de la imagen Docker.
Seguridad: el ingreso es obligatorio. Para acceso fuera de la red local use VPN o HTTPS con proxy inverso; no exponga PostgreSQL.
