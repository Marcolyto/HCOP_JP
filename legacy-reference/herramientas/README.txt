CARTERA DE HERRAMIENTAS CLINICAS URO NEURATALE

Contenido:
- index.html: consola unica de herramientas.
- css/styles.css: estilo visual alineado con el chat.
- js/app.js: logica local de calculo y render.
- manifest.json: descripcion de la consola.
- CREDITOS_REFERENCIAS.md: fuentes de referencia para validacion.

Uso:
1. Iniciar el servidor principal del chat.
2. Entrar a /herramientas/index.html.
3. Seleccionar herramienta, completar variables y revisar el resultado.

Nota clinica:
Las salidas son estimaciones orientativas para ordenar informacion clinica y facilitar QA. Cuando una decision dependa de un umbral exacto, confirmar en la calculadora oficial o guia vigente correspondiente.
